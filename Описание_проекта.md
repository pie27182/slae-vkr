# Состав и ограничения проекта

## Прямые методы решения

| Метод | Реализация | Назначение и ограничения |
|---|---|---|
| Метод Гаусса | Python и NumPy | Основной вариант использует выбор главного элемента. Вариант без такого выбора оставлен для отдельного сравнения устойчивости. |
| Разложение Холецкого | Python, NumPy и SciPy | Применяется к симметричным положительно определённым матрицам. |
| Алгоритм Томаса | Python и NumPy | Предназначен только для трёхдиагональных матриц. Не использует выбор главного элемента. |
| Решение плотной системы | NumPy | Используется стандартный решатель библиотеки; внутренний алгоритм определяет сама библиотека. |
| LU-разложение | SciPy | Реализованы плотный и разреженный варианты. |
| QR-разложение | SciPy | Прямой метод для плотных квадратных систем. |
| Сингулярное разложение | NumPy | Используется для решения задачи наименьших квадратов и допускает матрицы недостаточного ранга. |
| Специализированный трёхдиагональный решатель | SciPy | Принимает три диагонали матрицы в формате, предусмотренном библиотекой. |

## Итерационные методы

| Метод | Реализация | Условия применения |
|---|---|---|
| Метод Якоби | Python и NumPy | Требует ненулевую диагональ; сходимость зависит от свойств матрицы. |
| Метод Гаусса — Зейделя | Python и NumPy | Требует ненулевую диагональ; сходимость зависит от свойств матрицы. |
| Последовательная верхняя релаксация | Python и NumPy | Параметр релаксации должен быть больше нуля и меньше двух. Это условие само по себе не гарантирует сходимость. |
| Метод сопряжённых градиентов | Собственная реализация и SciPy | Требует симметричную положительно определённую матрицу. Код проверяет симметричность; положительную определённость должен подтвердить вызывающий сценарий. |
| Стабилизированный метод бисопряжённых градиентов | SciPy | Предназначен для более общего класса разреженных систем. |
| Обобщённый метод минимальной невязки | SciPy | Предназначен для более общего класса систем. В настройках задаётся число циклов перезапуска. |

## Предобуславливатели

- Диагональный предобуславливатель масштабирует компоненты с учётом диагонали матрицы.
- Симметричный предобуславливатель на основе последовательной верхней релаксации предназначен для симметричных матриц с положительной диагональю.
- Предобуславливатель на основе неполного LU-разложения применяется с методом бисопряжённых градиентов или методом минимальной невязки. Он не используется с методом сопряжённых градиентов, поскольку не гарантирует необходимую симметричность.

## Типы матриц

Генераторы создают плотные случайные матрицы, диагонально преобладающие матрицы, симметричные положительно определённые матрицы, матрицы с заданной обусловленностью, матрицы Гильберта, трёхдиагональные матрицы, случайные разреженные матрицы и матрицы дискретной задачи Пуассона.

Трёхдиагональная матрица имеет ненулевые элементы только на главной диагонали и двух соседних диагоналях.

## Что измеряет программа

Для решения каждой системы измеряются время работы, число итераций и показатели точности. Фактическая невязка пересчитывается независимо от внутреннего сообщения решателя о сходимости. Если известно заданное решение, дополнительно рассчитывается прямая ошибка. Для метода минимальной невязки с перезапуском поле числа итераций содержит число завершённых циклов перезапуска.

Время подготовки матрицы и правой части не входит во время решения. Перед измерением выполняется прогревочный вызов. Для быстрых методов собирается несколько повторных измерений. В таблице сохраняются медиана, квартильные значения, среднее, стандартное отклонение и число повторов.

## Внешние матрицы

Сценарий внешних данных предназначен для файлов формата Matrix Market из коллекции SuiteSparse. Список матриц задаёт пользователь. Скрипт загрузки проверяет имя, группу, размер и формат файла, после чего сохраняет манифест. Если контрольная сумма была сохранена при загрузке, файл проверяется перед расчётом.

Метаданные коллекции могут указывать, что матрица положительно определена. Это свойство не выводится из одной только симметричности. Если положительная определённость не подтверждена, методы, которым она необходима, отмечаются как неприменимые.

Правая часть внешней системы формируется как произведение матрицы на отдельно сгенерированный вектор. Такой способ позволяет сравнить вычисленное решение с исходным вектором, но не моделирует все возможные прикладные правые части.

## Файлы и результаты

Синтетические серии создают отдельные таблицы CSV в каталоге `results` или `results_quick`. Эксперименты на внешних матрицах создают `real.csv` и `matrices.csv` в каталоге `results_real`. Файл `run_config.json` содержит параметры синтетического запуска, а `environment.json` — сведения о программной и вычислительной среде.

Графики и сводный отчёт для синтетических экспериментов строятся отдельным запуском `experiments.plots`. Отчёт для внешних матриц создаётся программой `experiments.real_matrices`. В архив не включены готовые таблицы и изображения: они создаются при запуске на компьютере пользователя.

## Пояснение терминов

- **LU-разложение** представляет матрицу как произведение нижней и верхней треугольных матриц.
- **QR-разложение** представляет матрицу как произведение ортогональной и верхней треугольной матриц.
- **Метод сопряжённых градиентов** применяется к симметричным положительно определённым матрицам.
- **Стабилизированный метод бисопряжённых градиентов** и **обобщённый метод минимальной невязки** — итерационные методы для более широкого класса систем.
- **Предобуславливатель** — преобразование, которое может уменьшить число итераций при решении системы.
- **Невязка** — разность между правой частью системы и произведением матрицы на найденное решение.
- **Обусловленность** характеризует чувствительность решения к изменениям исходных данных.
- **Невырожденная матрица** имеет ненулевой определитель; соответствующая квадратная система имеет единственное решение.
- **Положительно определённая матрица** — симметричная матрица, для которой квадратичная форма положительна на любом ненулевом векторе.
- **Подпространство Крылова** строится по последовательным произведениям матрицы на вектор и используется несколькими итерационными методами.
