# Исследование методов решения систем линейных уравнений

Проект предназначен для проверки и сравнения численных методов решения систем вида \(Ax=b\). В него входят реализации решателей, генераторы тестовых матриц, программа измерения времени, сценарии экспериментов и автоматические тесты.

Готовые экспериментальные таблицы в архив не входят. Результаты и графики создаются при запуске программ на компьютере пользователя.

## 1. Что реализовано

**Прямые методы:** метод Гаусса с выбором главного элемента и отдельный вариант без такого выбора для исследования устойчивости, разложение Холецкого, алгоритм Томаса для трёхдиагональных систем, стандартный решатель NumPy, LU- и QR-разложения SciPy, а также решение задачи наименьших квадратов с помощью сингулярного разложения. Для трёхдиагональных систем также предусмотрен отдельный решатель SciPy; его результаты сравниваются с общими плотными и разреженными решателями.

**Итерационные методы:** методы Якоби и Гаусса — Зейделя, последовательная верхняя релаксация, метод сопряжённых градиентов, стабилизированный метод бисопряжённых градиентов и обобщённый метод минимальной невязки.

**Предобуславливатели:** диагональный, симметричный предобуславливатель на основе последовательной верхней релаксации и предобуславливатель на основе неполного LU-разложения.

**Генераторы матриц:** плотные случайные матрицы, диагонально преобладающие матрицы, симметричные положительно определённые матрицы, матрицы с заданной обусловленностью, матрицы Гильберта, трёхдиагональные матрицы, случайные разреженные матрицы и матрицы дискретной задачи Пуассона.

Программа также умеет загружать выбранные пользователем матрицы из коллекции SuiteSparse и проводить на них отдельные расчёты.

**Граница применимости трёхдиагонального решателя.** В проекте реализована работа только с трёхдиагональными матрицами: ненулевые элементы могут находиться на главной диагонали и двух соседних диагоналях.

## 2. Установка

Требуется Python версии 3.10 или новее.

```bash
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## 3. Проверка программы

```bash
python -m pytest -q
```

Тесты проверяют решения на известных системах, работу методов на плотных и разреженных матрицах, обработку некорректных входных данных, проверку невязки и отдельные сценарии чтения и загрузки матриц.

Тесты не требуют, чтобы какой-либо метод обязательно был быстрее другого. Скорость зависит от размера и свойств матрицы, процессора, используемых библиотек и настроек вычислений.

## 4. Очистка результатов

Удалить стандартные каталоги результатов и графиков:

```bash
python -m experiments.clean_results
```

Удалить также загруженные матрицы и служебные файлы коллекции:

```bash
python -m experiments.clean_results --include-data
```

Команда очищает только стандартные каталоги проекта. Она не удаляет исходный код, тесты, виртуальное окружение и каталоги, переданные вручную через параметры `--out`, `--data` или `--figures`.

## 5. Синтетические эксперименты

Сначала можно проверить весь конвейер на сокращённом наборе размеров и повторов:

```bash
python -m experiments.run_all --quick --seed 20261113
python -m experiments.plots --results results_quick --figures figures_quick
```

Для получения основных экспериментальных данных используйте полный профиль:

```bash
python -m experiments.run_all --seed 20261113
python -m experiments.plots --results results --figures figures
```

Без параметра `--quick` запускается полный профиль. Перед началом расчёта каталог результатов должен быть пустым. Это правило не позволяет случайно смешать таблицы от разных запусков. Для нового набора данных очистите стандартные каталоги или укажите новый путь через `--out`.

Можно запустить только выбранные серии. Например:

```bash
python -m experiments.run_all dense accuracy poisson --seed 20261113
```

Доступные серии:

| Имя серии | Содержание | Файл с данными |
|---|---|---|
| `dense` | Прямые методы на плотных системах | `dense.csv` |
| `iterative_methods` | Сравнение реализаций итерационных методов | `iterative_methods.csv` |
| `accuracy` | Точность на матрицах с разной обусловленностью | `accuracy.csv` |
| `conjugate_gradient_condition` | Влияние обусловленности на метод сопряжённых градиентов | `conjugate_gradient_condition.csv` |
| `poisson` | Решение дискретной задачи Пуассона | `poisson.csv` |
| `tridiagonal` | Решатели трёхдиагональных систем | `tridiagonal.csv` |
| `sparse` | Случайные разреженные системы | `random_sparse.csv` |
| `multiple_right_hand_sides` | Решение системы для нескольких векторов правой части | `multiple_right_hand_sides.csv` |
| `library_threads` | Влияние числа вычислительных потоков на время решения | `library_threads.csv` |
| `timing_variability` | Разброс повторных измерений времени | `timing_variability.csv` |

Сокращённый профиль предназначен для проверки работы программы. Его результаты не следует использовать вместо основного эксперимента в выводах исследования.

### Повторяемость

Параметр `--seed` задаёт начальное значение генераторов случайных чисел. Если его не указать, программа выбирает случайное значение и записывает его в `run_config.json`.

Для матрицы и правой части сохраняются отдельные начальные значения. В серии повторных измерений также сохраняется начальное значение генератора, определяющего порядок запуска методов. Чтобы повторить расчёт, используйте то же начальное значение, тот же профиль, тот же набор серий и те же версии библиотек.

Файл `environment.json` содержит версии Python и основных библиотек, сведения о процессоре, операционной системе и доступных вычислительных потоках. Файл `manifest.csv` (реестр загруженных матриц) хранит перечень загруженных матриц, сведения о них из каталога и контрольные суммы. Повторение одного запуска не заменяет независимые эксперименты на нескольких матрицах.

### Число вычислительных потоков

В основных сериях по умолчанию используется один вычислительный поток библиотек линейной алгебры. Это уменьшает влияние параллельного выполнения при сравнении алгоритмов. Число потоков можно задать параметром `--library-threads N`, где `N` — положительное целое число.

Серия `library_threads` сравнивает один поток с исходным числом потоков, сообщённым вычислительной библиотекой при запуске процесса. Это настройка библиотеки, а не измерение аппаратного максимума процессора. Если библиотека изначально настроена на один поток, серия записывает, что сравнение невозможно, и не строит фиктивный график.

## 6. Расчёты на матрицах из SuiteSparse

Для внешних матриц используется текстовый формат Matrix Market и каталог SuiteSparse — открытая коллекция тестовых разреженных матриц. Сначала проверьте параметры загрузчика:

```bash
python -m experiments.download_matrices --help
```

Укажите имена матриц из официального индекса:

```bash
python -m experiments.download_matrices ИМЯ_МАТРИЦЫ_1 ИМЯ_МАТРИЦЫ_2
```

Вместо условных имён укажите реальные имена матриц из официального списка. Если одно имя встречается в нескольких группах, задайте нужную группу параметром `--group ИМЯ=ГРУППА` (слева укажите имя матрицы, справа — название группы). Загрузчик не выбирает одну из неоднозначных записей автоматически.

После загрузки запустите расчёт:

```bash
python -m experiments.real_matrices --seed 20261113
```

По умолчанию используются файлы, которые отмечены в реестре загрузок как успешно загруженные. Параметр `--all-local` включает все локальные файлы `.mtx`, в том числе отсутствующие в реестре загрузок. Параметр `--only ИМЯ_1 ИМЯ_2` ограничивает расчёт указанными матрицами.

Чтобы повторно построить отчёт по уже имеющимся результатам:

```bash
python -m experiments.real_matrices --report
```

Пути к исходным данным, таблицам и графикам можно изменить параметрами `--data`, `--out` и `--figures`. Перед новым расчётом каталог результатов должен быть пустым.

### Ограничения расчётов на внешних матрицах

- Набор матриц выбирает пользователь. В исследовании необходимо объяснить критерии отбора, указать размеры, свойства и источник файлов. Несколько выбранных матриц не являются представительной выборкой всей коллекции.
- Метод сопряжённых градиентов и разложение Холецкого применяются, только если каталог указывает положительную определённость и матрица проходит проверку симметричности. Одна лишь симметричность этого свойства не доказывает.
- Для каждого исходного файла вычисляется контрольная сумма. При наличии сохранённой ранее суммы файл проверяется перед расчётом.
- Правая часть строится по формуле \(b=Ax\), где вектор \(x\) генерируется отдельно. Поэтому можно оценить ошибку относительно заданного вектора. Для вырожденной матрицы это не означает, что решение единственно.
- Для больших матриц действуют ограничения на плотные методы, учебную реализацию метода Гаусса и разреженное LU-разложение. Их можно изменить параметрами `--max-dense-n`, `--max-pure-n` и `--max-lu-nnz`.

## 7. Содержание файлов результатов

В основных таблицах используются следующие поля:

| Поле | Значение |
|---|---|
| `n` | Размер квадратной матрицы: число строк и столбцов |
| `N` | Число узлов вдоль одной стороны сетки в задаче Пуассона; размер матрицы в этой серии равен `N` в квадрате |
| `nnz` | Число ненулевых элементов матрицы; это стандартное краткое имя поля в программах для разреженных матриц |
| `time` / `time_median` | Время одного измерения или медианное время нескольких измерений, в секундах |
| `iters` | Число итераций, то есть повторных шагов метода; для метода минимальной невязки с перезапуском — число циклов перезапуска |
| `matrix_seed` | Начальное значение генератора случайных чисел при создании матрицы |
| `right_hand_side_seed` | Начальное значение генератора случайных чисел при создании правой части системы |
| `rel_error` | Относительная прямая ошибка относительно заданного решения, если оно известно |
| `rel_residual` | Относительная невязка \(\|b-Ax\|_2/\|b\|_2\) |
| `backward_error` | Обратная ошибка: \(\|b-Ax\|_\infty / (\|A\|_\infty\|x\|_\infty + \|b\|_\infty)\) |
| `status` | Итоговая оценка запуска после независимой проверки; значения пояснены ниже |

Подготовка матрицы и правой части не включается во время решения. Перед измерениями выполняется один прогревочный запуск. Для быстрых методов одно измерение может объединять несколько последовательных решений, чтобы уменьшить влияние накладных расходов самого измерения. В сериях с повторными измерениями сохраняются медиана, нижний и верхний квартили, среднее, стандартное отклонение и число повторов.

На графики времени попадают только решения, прошедшие независимую проверку невязки. Неуспешные запуски остаются в таблицах со своим статусом и не выдаются за успешные решения.

В таблицах используются короткие машинные обозначения статусов. Их значение пояснено в правом столбце:

| Значение | Пояснение |
|---|---|
| `solved`, `converged` | Решение прошло проверку невязки |
| `max iterations` | Достигнут предел числа итераций |
| `time limit` | Превышено ограничение времени |
| `diverged` | Итерационный процесс расходится |
| `breakdown` | Метод остановился из-за численной проблемы |
| `verification_failed` | Внутренний код метода сообщил об успехе, но независимая проверка невязки не пройдена |
| `exception` | Во время выполнения возникла ошибка |
| `n/a` | Метод неприменим к этой матрице |
| `not_available` | Для эксперимента нет необходимых возможностей вычислительной библиотеки |
| `out_of_memory` | Не хватило оперативной памяти для запуска метода |
| `non_finite` | Решатель вернул нечисловые значения или бесконечности |
| `loaded` | Файл матрицы прочитан и прошёл базовые проверки; этот статус относится к `matrices.csv` |
| `load_error` | Файл матрицы не удалось прочитать или проверить |
| `matrix_run_error` | Ошибка возникла при обработке матрицы в целом |

Поля `matrix_type`, `method`, `level` и `family` обозначают соответственно тип матрицы, название решателя, вариант его реализации и группу метода. Дополнительные поля, которые появляются в отдельных сериях: `time_min` и `time_q1` — минимальное время и первый квартиль; `time_q3` — третий квартиль; `time_mean` — среднее время; `time_std` — стандартное отклонение времени; `repeats` — число повторных измерений; `number` — число решений, объединённых в одно измерение; `warmup_time` — время прогревочного запуска. Поля `cond_target` и `cond_actual` содержат заданное и фактическое числа обусловленности. Поле `converged` показывает, достиг ли итерационный метод сходимости, а `solver_status` сохраняет исходный статус решателя до независимой проверки. Поле `error_message` содержит причину ошибки, если запуск завершился неудачно.

## 8. Термины и сокращения

- **СЛАУ** — система линейных алгебраических уравнений.
- **BLAS (Basic Linear Algebra Subprograms)** — стандартный набор базовых операций линейной алгебры. Библиотеки BLAS могут выполнять вычисления в нескольких потоках.
- **Плотная матрица** — матрица, в которой большинство элементов ненулевые. **Разреженная матрица** содержит сравнительно мало ненулевых элементов; для неё используют специальные способы хранения и решения.
- **Невязка** — вектор \(r=b-Ax\), показывающий, насколько найденное решение удовлетворяет исходной системе.
- **Невырожденная матрица** — квадратная матрица, для которой существует обратная матрица; при такой матрице решение системы единственно.
- **Симметричная положительно определённая матрица** — симметричная матрица, для которой \(x^T A x>0\) при любом ненулевом векторе \(x\). Это обязательное условие для метода сопряжённых градиентов.
- **Подпространство Крылова** — пространство векторов, построенное по последовательным произведениям матрицы на исходный вектор. На таких пространствах основаны несколько итерационных методов проекта.
- **Дискретная задача Пуассона** — система линейных уравнений, полученная приближением уравнения Пуассона на двумерной сетке.
- **Число обусловленности** — характеристика чувствительности решения к небольшим изменениям исходной матрицы или правой части.
- **Предобуславливатель** — дополнительное преобразование системы, которое может ускорить сходимость итерационного метода.
- **CG (Conjugate Gradient, метод сопряжённых градиентов)** — итерационный метод для симметричных положительно определённых матриц.
- **BiCGStab (Biconjugate Gradient Stabilized, стабилизированный метод бисопряжённых градиентов)** — итерационный метод для более общего класса систем.
- **GMRES (Generalized Minimal Residual, обобщённый метод минимальной невязки)** — итерационный метод, который ищет приближение в последовательности расширяющихся подпространств.
- **LU-разложение** — представление матрицы в виде произведения нижней и верхней треугольных матриц. Буква L означает нижнюю треугольную матрицу (lower), а U — верхнюю (upper).
- **QR-разложение** — представление матрицы в виде произведения ортогональной матрицы Q и верхней треугольной матрицы R; буквы Q и R — стандартные обозначения этих множителей.
- **Сингулярное разложение** — представление матрицы через ортогональные множители и диагональную матрицу сингулярных значений; используется в решении задачи наименьших квадратов.
- **Последовательная верхняя релаксация** — итерационный метод с параметром релаксации. Его симметричный вариант также используется как предобуславливатель.
- **Неполное LU-разложение** — приближённое разложение разреженной матрицы, используемое для ускорения некоторых итерационных методов.
- **CSR (Compressed Sparse Row, сжатое хранение по строкам)** — способ представления разреженной матрицы, при котором ненулевые элементы группируются по строкам.
- **Matrix Market** — текстовый формат записи матриц, используемый для обмена тестовыми матрицами.
- **CSV (Comma-Separated Values, значения, разделённые запятыми)** — текстовый формат хранения таблиц.
- **JSON (JavaScript Object Notation)** — текстовый формат хранения структурированных параметров запуска.
- **SHA-256** — алгоритм вычисления контрольной суммы длиной 256 бит. Он используется для проверки того, что файл не изменился после загрузки.
- **SuiteSparse** — открытая коллекция разреженных матриц для тестирования численных алгоритмов.
- **NumPy** и **SciPy** — библиотеки Python для численных вычислений и научной обработки данных.

Подробности реализации и ограничения методов приведены в [описании проекта](Описание_проекта.md).
